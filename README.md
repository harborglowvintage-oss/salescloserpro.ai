## What it is

SalesCloserPro is a sales tool for freelancers, contractors and small businesses. You build a
quote, send the client a link, they accept from their phone, and the deal moves through your
pipeline — with follow-up reminders for the ones that have not answered yet.

There is no account, no subscription and no server. Everything you enter is stored in your own
browser, and the app is free and open source under Apache-2.0.

## Features

| Area | What you get |
|---|---|
| **Quotes** | Product, service, labor and freight lines; sales tax for all 50 states and DC worked out per line; optional model numbers; attachments; sequential numbers that are never reused. |
| **Options** | Good / Better / Best — each option fully priced on the PDF and the client page. |
| **Sending** | A proposal link, a ready-to-send email draft, and a PDF with a clickable accept link. |
| **Acceptance** | The client picks an option and accepts by name. A version code confirms they accepted exactly what you sent, and warns you if you edited the quote afterwards. |
| **Follow-ups** | Reminders on the dashboard and the quote, drafted follow-up emails, and `.ics` export for Google, Outlook and Apple calendars. |
| **Contacts** | Type-ahead picker on quotes and deals; contacts are created or matched automatically when you save. |
| **Pipeline** | Lead → Quoted → Proposal Sent → Negotiating → Won / Lost, kept in step with quote status. |
| **Purchase orders** | Vendor POs linked to quote lines, with margin tables and charts. |
| **PDFs** | Proposals, purchase orders and the Business Summary share one clean layout with your logo. |
| **Export** | CSV in HubSpot, Salesforce and universal layouts. Files are made on your device; nothing connects to those services. |
| **Backup** | One-file backup and restore, with optional scheduled backups to a folder you choose. |
| **Everywhere** | Dark and light themes, phone-friendly screens, a built-in searchable help guide. |

## How "accept online" works without a server

1. **Send** packs the quote into the link itself, after the `#`. Browsers never transmit that
   part of a link, so the proposal is not uploaded to SalesCloserPro, to the host, or to anyone.
2. The client opens the link, chooses an option, types their name and accepts. That drafts a
   confirmation email in **their own** mail app, addressed to you.
3. You open the link in that email. The app matches it to your quote, checks the version code,
   and records the acceptance.

Anyone who has the link can read the proposal, exactly like an emailed PDF — send it only to
your client. Logos and attachments are not included in the link.

## Your data

| | |
|---|---|
| **Where it lives** | Your browser's IndexedDB, on your device. Clearing site data erases it — use **Backup**. |
| **What leaves your device** | Nothing, unless you send it: proposal links, emails from your own mail app, and files you download. |
| **Third parties** | The site is served by Cloudflare, and two typefaces load from Google Fonts. There are no analytics, ads or trackers. |
| **Moving devices** | Backup on one device, Restore on the other. There is no cloud sync. |

## Quick start

Requires Node 20 or newer (the repo pins Node 24 in `.nvmrc`).

```bash
git clone https://github.com/harborglowvintage-oss/salescloserpro.ai.git
cd salescloserpro.ai
npm install
npm run dev        # http://localhost:5173
```

| Script | What it does |
|---|---|
| `npm run dev` | Development server with hot reload |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm test` | Unit tests for pricing, proposal links, follow-ups, exports and upload safety |
| `npm run test:e2e` | Browser tests for every user flow (setup notes in [`tests/run-e2e.mjs`](tests/run-e2e.mjs)) |
| `npm run screenshots` | Regenerate `screenshots/` from demo data |
| `npm run generate-images` | Rebuild the social card and logos from `brand/` |

To host your own copy, see [DEPLOYMENT.md](DEPLOYMENT.md). Forks must use their own name and
logo — see [CONTRIBUTING.md](CONTRIBUTING.md).

## Good to know

- **Sales tax is a starting point, not advice.** Rates are built in for convenience; confirm
  them with your accountant before you invoice.
- **Terms on proposals are fixed** (50% deposit, net 30). Add anything else in the notes.
- **United States only for now** — US dollars and US state tax.
- **Export is one-way.** Files go to HubSpot or Salesforce through their own import tools;
  changes made there do not come back.
